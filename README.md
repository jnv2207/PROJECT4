# Data Analyzer and Transformer

## 1. Project Overview
Data Analyzer and Transformer is a menu-driven Python application designed to analyze, process, and transform numerical data. It allows users to enter 1D and 2D lists and perform different operations using Python programming concepts.

The project demonstrates the use of built-in functions, user-defined functions, recursion, lambda functions, and list operations.

## 2. Objectives
- To understand and implement Python functions.
- To analyze numerical datasets.
- To perform sorting and filtering operations.
- To identify duplicate and unique values.
- To demonstrate important Python programming concepts.
- To develop a menu-driven application.

## 3. Technologies Used
- **Programming Language:** Python
- **IDE:** Python IDLE / VS Code / PyCharm
- **Data Structures:** Lists, Tuples and Dictionaries

## 4. Features
1. Accept 1D and 2D numerical data.
2. Calculate sum, average, minimum and maximum.
3. Find duplicate values.
4. Display unique values.
5. Calculate factorial using recursion.
6. Filter data using lambda functions.
7. Use map() and filter().
8. Sort data in ascending and descending order.
9. Demonstrate *args and **kwargs.
10. Display function documentation using __doc__.
11. Update global variables.
12. Return multiple values from a function.

## 5. Python Concepts Implemented

| Concept | Description |
|---|---|
| Built-in Functions | len(), sum(), min(), max() |
| User-Defined Functions | Custom functions for calculations |
| *args | Accepts multiple positional arguments |
| **kwargs | Accepts multiple keyword arguments |
| __doc__ | Accesses function documentation |
| Recursion | Calculates factorial |
| Lambda | Creates anonymous functions |
| map() | Applies an operation to each element |
| filter() | Filters elements based on a condition |
| Global Keyword | Accesses and modifies global variables |
| Return Multiple Values | Returns multiple results |
| 1D and 2D Lists | Stores numerical data |
| Sorting | Uses sort() and sorted() |

## 6. How to Run the Project

1. Install Python on your computer.
2. Open Python IDLE or VS Code.
3. Create a new Python file named `data_analyzer.py`.
4. Copy the project source code into the file.
5. Save the file.
6. Run the program.
7. Select the required operation from the main menu.
